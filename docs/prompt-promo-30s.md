1. 单文件：HTML + 内联 CSS + 内联 JS。零外部依赖——不许引 CDN、不许联网字体、不许外部图片。
2. 舞台固定 1920×1080（16:9），用 transform: scale() 等比缩放并居中，适配任意窗口。
3. 打开自动播放，总时长恰好 30 秒，播完停在尾帧不循环；右下角放一个「↻ 重播」按钮。

5. 所有文案简体中文。字体用系统栈：-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif。
6. 不要用 canvas 画文字（可读性差），全部用 DOM + CSS 动画；canvas 只能用来画辅助图形。

- 强调数字用 800 字重 + 负字距，单位（kcal / g / mg）小一号且灰色
- 缓动统一 cubic-bezier(.22,1,.36,1)，单元素进场 400–600ms，错峰 60–90ms
- 金色拱门自己用 SVG 画（两段 path + 圆头描边），不许引用官方 logo 图片

## 代码结构要求
- 用一个 `TIMELINE` 数组集中管理每一幕的起止时间，浏览器里不要散落魔法数字
- 每一幕写成独立函数 `scene1()` … `scene6()`，各自返回 DOM 片段，主流程按时间轴挂载
- 数字滚动封装成 `countUp(el, from, to, duration)`，用 requestAnimationFrame 插值，保留千分位
- 所有动画只用 transform / opacity（不触发重排），必要时加 will-change
- 元素出现用 `data-in` 类切换，不要写一堆内联 style

## 禁止事项
- 不出现麦当劳官方 logo 位图、官方字体、官方门店实拍
- 不出现「官方」「授权」「合作」这类暗示性表述
- 不用 emoji 当图标；不用花哨的渐变彩虹色；不做弹跳过多的廉价动效
- 不要在画面上堆满字，每屏只留一句主文案 + 一组数字
